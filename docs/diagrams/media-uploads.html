media_assets — subida a Cloudflare R2

La tabla solo guarda metadata; el archivo vive en el bucket. Ver docs/MEDIA_UPLOADS.md.

Subida
ADMIN
POST /api/v1/admin/media (multipart/form-data, campo file)
↓
AdminMediaController → MediaAssetService.upload()
↓
R2
s3Client.putObject(...)
Key: {uuid}-{nombre-sanitizado}. Bucket: r2.bucket-name.
DB
mediaAssetRepository.saveAndFlush(...)
Fila con filename, url, contentType, sizeBytes, uploadedAt.
↓
201 — MediaAssetDto
url = r2.public-url + / + key, ej. https://media.rafotijero.dev/<key>
Servido al público — no pasa por el backend
PÚBLICO
Cliente pega la URL en Post.coverImageUrl, SiteProfile.cvUrl, etc.
→
R2
media.rafotijero.dev sirve el objeto directo
Dominio custom conectado al bucket — Cloudflare resuelve DNS/SSL, el backend no interviene.
Borrado
ADMIN
DELETE /api/v1/admin/media/{id}
↓
Deriva la key quitando r2.public-url del url guardado
↓
R2
s3Client.deleteObject(key)
mediaAssetRepository.delete(asset)
↓
204 — objeto y fila eliminados
